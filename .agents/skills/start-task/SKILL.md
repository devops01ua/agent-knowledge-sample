# Start task

1. Read the repository's `AGENTS.md` (the compass): commands, traps, dependencies.
2. Run the knowledge skill for the systems the task touches.
3. Summarise in five lines: what the task changes, which traps apply, what to verify.
4. Only then start changing files.
