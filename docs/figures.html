What and where

id, type, the repos and systems it is about. This is what search filters on.

Can I act on it

Can I trust it

How

An in-memory SQLite FTS5 table built on every call: about 0.2 s for a few hundred files, nothing to keep fresh. No FTS5: same pages, ordered by words held.
