Both instances authenticate people through SSO, so an engineer's own account can never
hold a long-lived API token. What the CLI stores after an SSO login is a session token
valid for 24 hours plus a refresh token. Lengthening the session for everyone was
considered and rejected. See [[wiki/systems/gitops-server]] and the source notes in
[[raw/2026-09-16-gitops-token-notes]].
